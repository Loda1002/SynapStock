**부합 근거**
- **devnet 온체인 tx 가 실재하고 확정됐다** — 서명 4건(배포 URL 세션 3 + CLI 증빙 1) 전부 `confirmationStatus=finalized` · `err=null`, 슬롯 480154256/480154304/480154322/480145341 (`getSignatureStatuses`, `searchTransactionHistory=true`)
