## 기준 불일치·미검증
- **신청 페이지 원문 미확보(전 축 공통)** — `docs/handoff.md:73` 기준, 사이트 JS 렌더링으로 조사 실패. 아래 항목은 전부 킥오프 전사 기반 해석이며 원문으로 확정되지 않았다.
- **축① 정식 항목명** — 전사는 '혁신성·UX·상업성'(`docs/hackathon_essentials_0721.md:23`), `docs/FEATURES.md:148` 은 '직관적·새로운 UX, 기존 문제 해결'. '상업성'이 독립 평가 항목인지, 소개서 필수 포함 항목(같은 문서 13행 '타겟 고객·문제/수익모델/아키텍처')일 뿐인지 미확정 — 수익모델 정량화 투자 규모가 여기 걸려 있다.
- **'당위성이 수상을 가른다'**(`hackathon_essentials_0721.md:57-59`)는 전사 기반 전략 인사이트로, 배점 항목인지 발표 권고인지 미검증.
- **라이브 배포 URL = 가산점**(`hackathon_essentials_0721.md:16` "| 보너스 | 라이브 배포 URL 제출 시 가산점 |")이며 필수 아님. 신청 페이지가 필수로 두었을 가능성은 미검증.
- **축② AI 스택 요건** — 전사는 "호출 수준이면 충분, ADK/Vertex 구조화는 가산점 아님"(`hackathon_essentials_0721.md:24`)인데 신청 페이지 계열 문구로 기록된 것은 "Gemini/Google Cloud AI 스택(에이전트 프레임워크 포함)"(`docs/FEATURES.md:149`). 두 기준이 실제로 다르면 ADK/Vertex 미사용이 감점 요인이 될 수 있으나 단정 불가.
- **대회 정식 주제** — 2차 매체 기준 "에이전트가 클라우드 API 를 발견·인증·결제"이고 공식 예시가 'Gemini 추론 호출 → 402 → USDC 차감 → API 접근'으로 서술된다(`docs/reports/competition_research.md:49, 388`). 사실이라면 축②·③의 정본 예시는 'Gemini API 자체를 x402 로 결제해 호출하는 것'인데 우리는 Gemini 를 무료 티어로 직접 호출하고 402 는 주식 브로커에 건다. 조사 문서 스스로 12개 해커톤 심사평 비공개·2차 매체 한계를 명시하므로 이번 평가에는 반영하지 않았다.
- **pay.sh 필수 여부** — 조사 문서는 필수로 서술(`competition_research.md:411`)하나 재분석에서 공식 페이지 확인 결과 필수 아님으로 뒤집혔다(`docs/reports/competition_research_reconcile.md:54-60`). 다만 이 역시 2차 매체 대조이지 신청 페이지 원문 확인이 아니다.
- **축③ 'USDC on Solana' 판정 기준** — 심사자가 자산 정체성(Circle 공식 민트)까지 보는지, 'USDC 규격(SPL 6 decimals)으로 레일을 구현했는가' 수준으로 보는지에 따라 위 민트 권한 문제의 감점 폭이 달라진다. 전사에 판정 기준 없음.
- **프로토콜 '공식 스펙 준수' vs '개념 채택'** — 전사는 AP2·A2A·x402 를 '등'이 붙은 병렬 예시로만 나열한다. 우리 AP2 는 SD-JWT/VC 가 아닌 ed25519 재구성이므로 전자 해석이면 감점 요인.
- **Solana 공식 'Subscriptions & Allowances'(사전 승인 지출 상한)** 가 pay.sh 스택 안에서 샌드박스/devnet 가용인지 미확인(`competition_research_reconcile.md:60`). 가용하다면 '누적 예산 상한'이 그쪽 레일에도 있으므로, **확인 전까지 "누적 예산 상한은 우리만의 것"이라 말하면 안 된다.**
- **축④ 평가 네트워크 동격 여부** — 전사는 'Devnet 또는 Localnet'을 동격으로 보지만 localnet 증빙은 외부 검증 불가(explorer customUrl=127.0.0.1)라, 신청 페이지가 '심사위원이 직접 조회 가능한 tx'를 요구하면 우리 증빙 8건 중 실효는 devnet 1건뿐이 된다.
- **'실행 로그'의 요구 수준**(파일 아카이브로 충분한가, 실시간 관측 대시보드가 필요한가)이 전사에 없다. 현재는 파일 아카이브 + 배포본 `/api/history` 로 대응.
