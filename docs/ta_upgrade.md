# TA(기술적 분석) 판단 보강 라운드 — 설계 결정·백테스트 실측 (2026-07-23 밤)

> 출처: 사용자 제공 매매 기준 분석 프롬프트(6개 이미지 분석 결과, message 2026-07-23).
> 원칙: **산수는 코드가, 해석은 판단자(Gemini/규칙)가** — 모델에게 계산을 시키지 않는다.

> 투자 조언이 아니다(데모용).

## 2. 설계 결정 (message 정정·열린 결정 반영)

1. **★정정 — 상승 쐐기형 = 매도(약세)**: 원본 이미지 3의 "매수경고 100%" 배정은 오류.
   표준 TA·이미지 5 기준으로 매도(신뢰 90)로 분류. 하락 쐐기형 = 매수(80).
2. **비게 된 매수 100% 칸**: 사용자 확인대로 100% 유지하되, 표준 TA 최강 상승 반전인
   **역헤드앤숄더·삼중바닥**을 배정. 이 수치들은 "사람에게 강도의 느낌을 주는 값"이라
   극단 조건이며 추후 테스트로 조정 가능(사용자 메모 그대로 코드 주석에 기록).
3. **룩백 "N=2" 해석**: 봉 수 2로는 어떤 패턴도 성립하지 않아 **유효 터치 2회 + 피벗
   강도 2봉**(좌우 2봉 극점)으로 해석, 탐지 창은 40봉. 전부 `indicators.py` 상단 상수로
   조정 가능.
4. **미탐지 TODO**: 상승/하락 깃발형·다이아몬드·역V자 — 탐지 난도 대비 가치가 낮아 v1
   제외(경제성 판단). 프롬프트 매핑에는 포함되어 있어 Gemini 는 개념적으로 인지하며,
   추후 탐지기만 추가하면 된다.
5. **개시 게이트 유지**: TA 는 거부권/보류권(사지마·팔지마·대기패턴·충돌=hold)으로만
   작동하고, 매수·매도의 "개시"는 기존 지표 규칙(MA5 −2% / 평단 +3%)이 게이트.
   AP2 한도 검사는 손대지 않음(한도=기계, 판단=AI 경계 불변).

## 3. 백테스트 실측 (AAPL 2026-06-01~07-22, 36봉, 예산 100 USDC, 수수료 0.3%)

| 두뇌 | 수익률 | MDD | 매매(매수/매도) | 승률 | 폴백 |
|---|---|---|---|---|---|
| 규칙 (기존) | +4.90% | 7.31% | 4/1 | 100% | — |
| **규칙+TA** | **0.00%** | 0.00% | **0/0** | — | — |
| Gemini 엄격 (무TA, 07-23 기존 실측) | +4.29% | — | — | — | 0 |
| **Gemini 엄격+TA** | **+4.95%** | **7.24%** | 4/1 | 100% | 0 |
| Gemini 추세 (무TA, 07-23 기존 실측) | +1.65~2.90% | 5.00% | — | — | — |
| **Gemini 추세+TA** | +2.19% | **4.84%** | 2/1 | 100% | 0 |

전 구간(2026-03-27~07-22, 80봉)에서도 규칙 +4.90% vs 규칙+TA 0.00%로 동일
(매수 신호 4건이 전부 6월에 발생, TA 거부권이 4건 모두 차단).

### 해석

- **Gemini 엄격+TA 가 전 모드 최고 수익률(+4.95%)** — TA 입력 보강이 엄격 모드
  수익률을 +0.66%p 올리고 MDD 도 소폭 낮췄다(7.31→7.24). message 의 목표
  "기존 대비 수익률 개선을 수치로"를 충족.
- **결정적 규칙+TA 는 이 구간에서 매수를 전부 차단**: 딥바잉(MA5 −2%) 시점은
  대개 중기선(MA10) 하락 중("사지마")이거나 상승 채널(대기 패턴) 안이라, 문헌을
  충실히 인코딩한 경직된 거부권은 상승장 딥바잉 전략과 구조적으로 충돌한다.
  같은 TA 를 **증거로** 받은 Gemini 는 균형 판단으로 엣지를 유지했다 —
  "규칙만으로는 부족하고 AI 판단이 가치를 더한다"는 소개서 서사의 실측 근거.
- 추세+TA 는 기대대로 저위험 프로파일(MDD 4.84%, 최저): 재량 보류로 매수 2건 스킵.

### 권고 (토글 기본값 — 사용자 "추천 받겠음"에 대한 답)

- **토글 기본 OFF 유지** (message 가드레일: 개선 확인 전 기존 로직이 기본값).
- **Gemini 세션에서는 ON 권장** — 수치로 개선 확인됨. 데모 시나리오도 ON 추천.
- 트레이드오프: TA ON 세션에서 Gemini 쿼터가 소진되면 폴백이 "규칙+TA"가 되어
  상승장 매수가 억제될 수 있다(보수적 방향이라 안전하지만 기회비용 존재).
  429 쿨다운이 짧으면 다음 틱에 Gemini 로 복귀하므로 영향은 제한적.

## 4. 재현 명령

```
python -m scripts.test_indicators                                              # 단위테스트 44건
python scripts/backtest.py --brain rule   --from 2026-06-01 --to 2026-07-22    # 기존 규칙
python scripts/backtest.py --brain rule   --ta --from 2026-06-01 --to 2026-07-22
python scripts/backtest.py --brain gemini --mode strict --ta --from 2026-06-01 --to 2026-07-22
python scripts/backtest.py --brain gemini --mode trend  --ta --from 2026-06-01 --to 2026-07-22
```

※ Gemini 런은 **동시 실행 금지**(429 쿨다운 충돌 → 폴백 오염), 순차로만.
결과 JSON 은 `artifacts/backtests/` 에 저장(20260723_20* 6건 커밋 — 규칙/규칙+TA 는
36봉·80봉 두 구간, Gemini 는 엄격+TA·추세+TA).
