# 랜딩 페이지 — 디자이너 전달 문서

세로로 흐르는 한 장짜리 소개 페이지입니다. **블록 11개**이고, 각 블록마다
**성격 / 화면에 그대로 들어갈 글자 / 지켜야 할 것**을 적었습니다.
글자 수는 공백 포함 실측치입니다. **읽는 데 20분이면 충분합니다.**

---

## 먼저 3분 — 이것만 알고 시작하시면 됩니다

**① 배치는 제안입니다.** 1부의 그림은 "이렇게 하세요"가 아니라 **어떤 정보가 한 덩어리이고
무엇이 먼저 와야 하는지**를 보여드리는 것입니다. 옮기고 합치고 나누셔도 됩니다.
`[고정]` 표시가 붙은 것만 순서를 지켜 주세요.

**② 글자는 최종본입니다.** 적힌 그대로 화면에 박힙니다. 자리표시자는 한 줄도 없습니다.

**③ 절대 바꾸면 안 되는 것 세 가지**

| | 무엇 | 왜 |
|---|---|---|
| 1 | **제품 이름은 `SynapStock`** | ⚠ 시안 좌측 상단이 `402 Guard` 로 되어 있는데, 그건 제품 **안에 있는 기능 이름**입니다. **브랜드 자리만** 바꿔 주세요 — 본문 안의 `402 Guard` 는 전부 맞습니다 |
| 2 | **`0.00 USDC` 는 설명 문구와 떼면 안 됨** | 그 숫자는 "**서명하기 전 단계**에서 한 푼도 안 샜다"는 뜻입니다. 설명 없이 크게만 띄우면 무제한 주장이 되고, 질문 한 번에 무너집니다 |
| 3 | **숫자는 실측치라 못 바꿈** | `8종` · `97.50%` · `23종` · `19,264줄` 등. 반올림도 안 됩니다(`97.5%` 아님). 화면·발표·영상이 전부 같은 숫자로 맞춰져 있어서, 여기만 달라지면 영상을 다시 찍어야 합니다 |
