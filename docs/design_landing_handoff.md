## 0. 읽는 법 — 먼저 두 가지

**① 1부의 배치 스케치는 지시가 아닙니다.** "구조를 그대로 따라갈 필요는 없다"고 하신 그대로,
이 스케치는 **정보의 묶음 · 순서 · 비중**을 전달하기 위한 것입니다. 어느 자리에 무엇이 오는지
합의하려는 것이 아니라, **무엇과 무엇이 붙어 있어야 뜻이 통하는지**를 보여드리려는 것입니다.
블록을 옮기거나 합치거나 나누셔도 됩니다 — `[고정]` 표시가 붙은 것만 예외이고, 왜 고정인지
한 줄로 이유를 적어 두었습니다.

**② 2부의 워딩은 전부 최종본입니다.** 자리표시자나 "~같은 문구"는 한 줄도 없습니다. 적힌
글자가 그대로 화면에 박힙니다. 글자 수(공백 포함)를 함께 적었으니 레이아웃 잡으실 때 쓰시면
됩니다. 줄바꿈 위치가 정해진 것은 제약란에 따로 적었습니다.

### 반드시 지켜야 하는 이름 규칙 (딱 하나입니다)

| | 무엇 | 어디에 쓰나 |
|---|---|---|
| **SynapStock** | **제품 이름** | 브랜드 자리, 탭 제목, 로고 |
| **402 Guard** | 그 제품 **안에 있는 기능 이름**(지출 승인 게이트) | 기능을 설명하는 문장 안 |

⚠ **첨부해 주신 시안의 좌측 상단 브랜드가 `402 Guard` 로 되어 있습니다. 거기는 `SynapStock`
이어야 합니다.** 기능 이름이 제품 이름 자리에 올라가 있는 것이라, 그대로 나가면 심사위원이
제품 이름과 기능 이름을 같은 것으로 읽습니다. 반대로 **본문 안의 `402 Guard` 는 전부 맞습니다**
— 일괄 치환하지 마시고 브랜드 자리 한 곳만 바꿔 주시면 됩니다.

# 2부 · 블록 명세

성격 태그는 주신 네 가지(**서비스 목표 / 서비스 과정 / 기능 설명 / 단계**)를 기본으로 쓰되,
안 맞는 네 개만 새로 만들었습니다.

| 새 태그 | 왜 새로 만들었나 |
|---|---|
| **내비게이션** | 정보가 아니라 이동 수단이라 네 가지 어디에도 안 들어갑니다 |
| **근거·증거** | 기능 설명이 아니라 "그 말이 사실이라는 증거"입니다. 이 해커톤은 그 칸을 따로 채점합니다 |
| **신뢰 고지** | 제품이 **하지 못하는 일**을 적는 칸이라 기능 설명의 반대편입니다 |
| **행동 유도** | 읽을 정보가 아니라 누를 것입니다 |

## B3 · 대시보드 화면 예시

**성격** 기능 설명

**최종 워딩**

| 요소 | 워딩 |
|---|---|
| 블록 라벨 | `대시보드 화면 예시` |
| 상단 바 | `SynapStock` · `유출 0.00` · `devnet · dry` |
| 배너 제목 | `402 Guard — 에이전트 지출 승인 게이트` |
| KPI 라벨 4개 | `지출 시도` · `가드 차단` · `한도 거부` · `유출 (목표 0.00)` |
| 왼쪽 카드 제목 | `시세` |
| 오른쪽 카드 제목 | `가드 로그 — 서명 직전 판정` |
| 로그 줄 1 | `차단  GUARD_PAYEE_UNKNOWN` / `수취인이 합의한 상대가 아님` |
| 로그 줄 2 | `차단  GUARD_SEMANTIC_MISMATCH` / `금액은 맞는데 청구서 설명이 주문과 다름` |
| 로그 줄 3 | `서명  STOCK:tAAPL x 0.05` / `수취인 · 금액 · 자산 · 설명 일치` |

**제약**
- ⚠ **`실시간` · `라이브` 라는 말을 붙이면 안 됩니다.** 이 블록은 손으로 만든 정적
  이미지입니다. 이 해커톤은 목업을 심사에서 제외하는데, 정적 화면에 '실시간' 라벨이
  붙어 있는 걸 들키면 **실제 온체인 증빙까지 의심받습니다.** 라벨은 반드시
  `대시보드 화면 예시` 입니다.
- 같은 이유로 **숫자는 흐리게 처리해 주세요**(라벨·구조·차트는 선명하게, 수치만 블러).
  전체 블러는 무슨 기능인지 안 보여서 전달이 안 됩니다. 디자인이 확정되면 이 자리를
  **실제 스크린샷**으로 교체할 예정이라, 그때 블러만 걷으면 되도록 잡아 주시면 좋습니다.
- `GUARD_PAYEE_UNKNOWN`·`GUARD_SEMANTIC_MISMATCH` 는 **코드에 실제로 있는 차단 코드**라
  철자 고정입니다(대문자·언더바 그대로). 한글로 풀지 마세요 — 원문 그대로여야 "화면이
  코드에서 나온 값"으로 읽힙니다.
- `tAAPL` 은 저희가 발행한 테스트 주식 토큰의 티커라 고정입니다.

**성격** 근거·증거

**최종 워딩**

| | 큰 글자 | 아래 설명 | 글자 수 |
|---|---|---|---|
| 1 | `0.00 USDC` | `서명 전에 가드를 태운 청구서에서 새어나간 금액` | 9 / 26 |
| 2 | `예산을 코드가 집행` | `표시용 한도가 아니라 AP2 위임장에서 실제 차감` | 10 / 27 |
| 3 | `사는 쪽·파는 쪽 대칭` | `돈이 나갈 때만이 아니라 자산이 나갈 때도 대조` | 12 / 26 |

**제약**
- ⚠ **`0.00 USDC` 는 설명 문구와 반드시 붙어 있어야 합니다.** `유출 0.00` 만 크게 떼어
