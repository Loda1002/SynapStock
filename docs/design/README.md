| 파일 | 내용 | 상태 |
|---|---|---|
| `dashboard_mockup.png` | 대시보드 디자인 시안(2026-07-25 도착, 멀티종목 엔진 이전 기준 프로토타입) | **사용자가 저장·커밋 예정** |

## 사용 규칙

- 시안은 **배치·색·간격·컴포넌트의 기준**이다. 픽셀 단위 복제가 아니라 **레이아웃·룩의 근거**로 쓴다.
- 시안은 프로토타입이라 **멀티종목 UI·가드 KPI 카드가 빠져 있고, 카피가 옛 "Auto Trader" 서사**다.
  반영 규칙(메시징 402 Guard 재조정·빠진 요소 추가)은 **[docs/frontend_kickoff.md](../frontend_kickoff.md) §3·§4** 를 따른다.
