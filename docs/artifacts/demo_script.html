장면 6개, 합계 180초. 왼쪽 타이머를 켜고 촬영하면 현재 장면이 자동으로 따라옵니다. 대사는 그대로 읽어도 되고, 강조된 문장만 지켜도 논지는 유지됩니다.

3분 초과 시 타이머가 빨갛게 바뀌고 초과분을 음수로 셉니다.

말할 것

AI 에이전트가 사람 없이 지갑으로 결제하는 시대가 옵니다. 그런데 x402 결제 규격은 파는 쪽을 보호하도록 설계돼 있고, 사는 쪽 — 사람 없이 서명하는 구매 에이전트 — 을 지키는 계층이 비어 있습니다. 저희는 그 비어 있는 절반을 만들었습니다.

보여줄 것

  • 제목 화면: 402 Guard — 에이전트 지출 승인 게이트
  • 한 줄 도식: 구매 에이전트 → [ 게이트 ] → 브로커
주의 이 20초 안에 '트레이딩 봇'이라는 단어를 쓰지 않습니다.

말할 것

악성 브로커가 건별 한도 45달러 안쪽인 44.94달러를 청구합니다. 금액은 정상입니다. 수취인 지갑 주소만 자기 것으로 바꿉니다. 지금 업계 기본값인 가드 없는 에이전트는 이걸 그대로 서명합니다. 돈은 나가고 주식은 오지 않습니다. 한도는 지켜졌는데 전액을 잃습니다.

보여줄 것

  • 가드를 끈 상태로 공격 실행 — 라벨은 가드 없는 일반 에이전트
  • 수취인 주소가 다른 지갑으로 바뀐 청구서를 화면에 확대
  • 한도 검사만 통과하는 순간을 그대로 노출
근거 AP2 authorize는 종목·건별한도·잔여예산만 보고 수취인은 검사하지 않는다 — 이 결함이 게이트의 존재 이유입니다.

말할 것

같은 공격을 402 Guard를 켜고 다시 돌립니다. 게이트는 서명 직전에 청구서를 사용자가 서명한 위임장과 대조합니다. 주문번호, 자산, 종목, 수취인, 금액, 사용자가 의도한 지출 상한, 건별 한도 — 하나라도 어긋나면 서명하지 않습니다. 결과는 시도 20건 중 6건 차단, 유출 0.00 USDC입니다.

보여줄 것

  • 터미널: python -m scripts.red_team --report
  • 공격·차단 매트릭스와 차단 코드를 정지 화면으로
  • 대시보드 KPI 카드: 시도·차단·유출 0.00·오탐 0
실측 시도 20 · 차단 6 · 유출 0.00 USDC · 오탐 0 (정상 14건 전부 통과)

말할 것

정상 거래는 막히지 않습니다. 브로커는 진짜 원격 서비스라 결제 없이 주문하면 402 Payment Required를 그대로 돌려줍니다. 결제를 붙이면 Solana에서 USDC가 실제로 이동합니다. 트랜잭션 메모에 주문번호를 심어 어느 주문인지 체인에서 대조할 수 있고, 정산 뒤에는 잔액을 다시 조회해 청구서대로 도착했는지 확인합니다.

보여줄 것

  • 터미널: curl -i http://localhost:8402/broker/orders → 402 응답 헤더·결제 조건 확대
  • 정상 매수 1건 — 판단 → 견적 → 게이트 통과 → 결제 완료
  • explorer에서 ?cluster=devnet 트랜잭션 실제 조회
  • 메모 필드 AT1:{order_id} 확대
  • 증빙 파일 artifacts/tx/ 교차검증 수치
실측 devnet 라이브 5거래 전부 확정, USDC 순변화 −4.9가 기대치와 일치

말할 것

판단은 Gemini가 합니다. 시세와 지표를 보고 사고팔지를 스스로 정합니다. 하지만 AI가 무엇을 판단하든 한도를 넘길 수는 없습니다. 사람이 미리 서명한 정책을 코드가 매 건 강제하기 때문입니다. 사람을 부르지 않고도 안전한 자율 결제 — 이게 저희가 만든 것입니다.

보여줄 것

  • 판단 타임라인에서 [gemini] 배지와 한국어 판단 이유
  • 한도 초과 시도 → 기계적 거부 1건
  • 여러 종목이 각자 예산 안에서 독립적으로 도는 화면
정직하게 수익률은 팔지 않습니다. 벤치마크에 지는 구간도 소개서에 그대로 실었습니다.

말할 것

저희가 파는 것은 수익률이 아니라 지출 통제입니다. 첫 화면의 숫자도 수익률이 아니라 시도·차단·유출 0.00·오탐 0입니다. 명령 한 줄이면 이 결과를 그대로 재현하실 수 있습니다.

보여줄 것

  • KPI 화면 정지 + 재현 명령 python -m scripts.red_team --report
  • 저장소 주소와 (배포되면) 라이브 URL
끝맺음 마지막 3초는 KPI 화면을 말없이 정지해 둡니다.
