```bash
git stash            # 작업 중인 변경 잠시 보관 (이미 커밋했다면 생략)

git stash pop        # 충돌이 나면 그 파일만 손으로 합칩니다
```

> ⚠ **왜 이걸 먼저 확인하나 — 지난 두 번 실제로 났던 사고입니다.** 그때 받은 파일들은 저장소보다

## 1. 이번 라운드에 확정된 결정 2가지

### 결정 1 — 개발 노브는 **지우지 않고 「고급」 뒤로 접습니다**

이 노브들은 우리가 실제 검증에 쓰기 때문에 없애면 재현성이 떨어집니다. 그래서 **분리**입니다.

- 세션 설정 카드를 **간단(기본) / 고급(접힘)** 으로 나눕니다.
- 고급을 펼치기 전에는 **현재 설정을 한 문장으로** 보여 줍니다
  (예: `실데이터 · 상승장 일봉 · 추세추종 · 빠름`).
- 주소에 **`?lab=1`** 이 붙어 있으면 처음부터 고급이 펼쳐진 채로 열립니다(우리 검증용 북마크).
- **`/lab` 같은 별도 경로는 만들지 않습니다** — 라우트 신설은 백엔드 파일을 건드리고,
  무엇보다 대시보드 화면이 사실상 두 벌이 되어 마감 6일 전에 회귀 표면이 2배가 됩니다.

### 결정 2 — 반영이 먼저, 촬영이 나중 (7/30~31)

관제탑 일정이 "①촬영 먼저"였는데 **②반영 먼저**로 바뀌었습니다. 그래서 §0-3 의 마감이 생겼습니다.

```js
const d=document.querySelector('.guard-dock').getBoundingClientRect();
```
