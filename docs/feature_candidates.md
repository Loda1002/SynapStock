# 편의 기능 후보 리스트 (사용자 선택 대기)

> 2026-07-22 상담에서 작성. 사용자가 이 중 3~5개를 선택하면 웹 서비스화(로드맵 1단계) 계획에 반영한다.
> 원칙: 전부 구현하면 난잡해진다 — 선택과 집중. 선택 결과는 이 문서에 기록.

## A. 있으면 무조건 좋은 기능 (기본기 — 신뢰·통제·가시성)

| 번호 | 기능 | 설명 | 난이도 |
|---|---|---|---|
| A1 | 실시간 대시보드 | 시세·포지션·예산·에이전트 대화 한 화면 — 로드맵 1단계에 이미 포함 | (예정) |
| A2 | 긴급정지 버튼 | 자율 매매 즉시 중단(킬스위치). "무섭지 않은 자율"의 핵심 통제장치 | 쉬움 |
| A3 | 한도·규칙 설정 화면 | 예산/건별 한도/허용 종목을 UI에서 변경 + mandate 재서명 | 보통 |
| A4 | 거래 알림 | 체결·거부 시 즉시 알림(브라우저 알림 또는 텔레그램 봇) | 보통 |
| A5 | 거래 내역 페이지 | 전체 기록 + explorer 링크 + CSV 내보내기 | 쉬움 |
| A6 | AI 판단 타임라인 | 매 틱의 판단·이유 기록 열람 (decision_source/reason 데이터 이미 존재) | 쉬움 |
| A7 | 손익 리포트 | 실현손익·수익률·평균단가 카드 | 쉬움 |
| A8 | 수수료 투명화 | 브로커 수수료(예 0.3%) 도입 + 견적·영수증 표시 — 수익모델 증명 직결 | 쉬움 |

## B. 있으면 참신한 기능 (차별화 — 데모 임팩트)

| 번호 | 기능 | 설명 | 난이도 |
|---|---|---|---|
| B1 | 자연어 규칙 설정 | 사용자가 말로 쓴 규칙("178 밑이면 30달러씩")을 Gemini가 규칙 JSON으로 변환 → mandate 서명. Gemini 심사축 강화, 데모 오프닝 장면 | 보통 |
| B2 | 에이전트 데일리 브리핑 | 하루 매매 활동을 Gemini가 한국어 리포트로 요약 | 쉬움 |
| B3 | 멀티 브로커 견적 경쟁 | 복수 브로커 견적 → 최저가 체결 (멀티에이전트 서사 심화) | 보통 |
| B4 | 리스크 가드 에이전트 | 급변동 감지 시 자동 일시정지하는 제3의 감시 에이전트 | 보통 |
| B5 | What-if 미리보기 | 규칙 변경 시 최근 시세 기반 가상 결과 미리보기 (백테스트 라이트) | 무거움 |
| B6 | 에이전트에게 질문 | 대시보드 채팅으로 상태 기반 질의응답 ("지금 왜 안 사?") | 보통 |
| B7 | 적립식(DCA) 모드 | 조건 매매 대신 정기 정액 매수 전략 옵션 | 쉬움 |

## 참고: 심사 임팩트 대비 난이도 기준 추천 조합 (선택은 사용자)

- 기본기: A2(긴급정지) + A5(내역) + A6(판단 타임라인) + A8(수수료)
- 참신: B1(자연어 규칙) + B2(브리핑)

## 관련 근거

- 심사 4축 ①혁신성·UX·상업성 — 소개서에 수익모델 필수(A8 연계)
- "검증&가드레일 레이어가 유망" (0721 세션 인사이트) — A2·A3·B4가 이 레이어
- 수수료 참고: 솔라나 네트워크 수수료는 tx당 0.000005 SOL(1원 미만, 데모에서 실측 5000 lamports). 브로커 매매 수수료는 현재 0으로 모델링 — A8 선택 시 견적·AP2 한도·Gemini 프롬프트 3곳에 반영 필요.
