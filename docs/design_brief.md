## 파트 B — 첨부 문서 (디자이너에게 그대로 전달)

### B1. 서비스와 사용자 흐름

**AutoTrader Agent**: 사용자가 "예산 100 USDC, 한 번에 최대 50까지"처럼 한도를 정하면,
AI 에이전트가 시세를 보고 스스로 매수·매도를 판단해 블록체인(솔라나)에서 결제까지 끝내는 서비스.

사용자 흐름 (화면 이동 순서):
```
랜딩(서비스 소개) → 회원가입/로그인 → 대시보드
대시보드 안에서: 한도 설정 → 세션 시작 → AI 판단·체결 실시간 관찰
              → (필요 시) 긴급정지/재개 → 세션 종료 → 데일리 브리핑 확인
```

### B2. 대시보드 화면 요소 (첨부 스크린샷과 대조)

| # | 요소 | 설명 |
|---|---|---|
| 1 | 상단 바 | 서비스명+한줄 소개 / 상태 배지(네트워크·엔진 상태·판단 모듈·🛑정지) / 컨트롤(실행 모드·전략 선택, 세션 시작/종료, 긴급정지/재개, 알림 토글) / 현재 규칙 요약 한 줄 |
| 2 | 시세 카드 (전체 폭) | 현재가 크게, 등락률, 캔들차트(양봉/음봉)+이동평균선 2종(MA5·MA20)+범례 |
| 3 | 포지션 카드 | 보유 수량, 평균단가 |
| 4 | 예산 카드 | 사용/잔여 게이지 바, 사용·총액·잔여·건별 최대 수치 |
| 5 | 한도 설정 카드 | 숫자 입력 2개(총예산, 건별 최대)+적용 버튼 폼 |
| 6 | 손익 카드 | 실현손익(＋면 초록/－면 빨강), 수익률 %, 누적 수수료 |
| 7 | 평가손익 카드 | 미실현 손익, 보유 평가액, 총자산 |
| 8 | AI 판단 타임라인 (넓은 카드, 내부 스크롤) | 판단 1건 = 1행: 시각·매수/매도/보류·이유 문장·출처 배지(4색: AI/규칙/폴백/적립) |
| 9 | 협상·이벤트 로그 (넓은 카드, 내부 스크롤) | 시스템 이벤트 피드 — 견적·결제 요구·제출·완결·거부 등 |
| 10 | 데일리 브리핑 카드 | 요약 생성 버튼 + AI가 쓴 하루 요약 문단 |
| 11 | 거래 내역 (전체 폭, 표) | 10열 표: 시각/방향/수량/단가/수수료/총액/판단/상태/결제 tx 링크/전달 tx 링크 |
| 12 | 푸터 | 서버 연결 상태, 지갑 주소 2개(축약 표기) |
| 13 | 토스트 알림 (우하단 겹침) | 체결·거부·정지 등 이벤트 알림 카드, 몇 초 뒤 사라짐 |

**디자인이 필요한 상태들**: 대기(데이터 없음 빈 상태) / 실행 중 / 🛑긴급정지(경고 배지) /
오류·서버 연결 끊김 / AP2 한도 거부(로그에서 강조되어야 함) / 토스트 알림.

### B3. 디자인 토큰 — 이 표에 값만 채우면 적용 끝

현재 값은 개발자가 임시로 넣은 것. **변수 이름은 고정, 값(라이트/다크 각각)만 새로 정해 주세요.**

| 변수 | 용도 | 현재 라이트 | 현재 다크 |
|---|---|---|---|
| --bg | 페이지 바탕 | #f4f5f7 | #14161a |
| --card-bg | 카드 바탕 | #ffffff | #1e2126 |
| --text | 본문 글자 | #1c2330 | #e6e9ee |
| --muted | 보조 글자 | #6b7480 | #9aa3ad |
| --border | 테두리 | #dfe3e8 | #343a42 |
| --accent | 강조(버튼·링크·MA5선) | #4f6ef7 | #7c93ff |
| --danger | 위험(정지·오류) | #e5484d | #ff6b6e |
| --ok | 성공(체결·연결됨) | #2f9e68 | #3ecf8e |
| --warn | 주의(거부·폴백) | #c97e0a | #f0b429 |
| --buy | 매수·양봉(상승) | #2f9e68 | #3ecf8e |
| --sell | 매도·음봉(하락) | #e5484d | #ff6b6e |
| --badge-gemini | AI 판단 배지 | #7c5cff | #9d86ff |
| --badge-rule | 규칙 판단 배지 | #6b7480 | #7d8590 |
| --badge-fallback | 폴백 판단 배지 | #c97e0a | #f0b429 |
| --badge-dca | 적립식 배지 | #0f7ea8 | #2fa8d5 |
| --font | 본문 글꼴 | system-ui 계열 | (동일) |
| --mono | 숫자·주소·코드 글꼴 | Consolas 계열 | (동일) |
| --radius | 모서리 반경 | 10px | (동일) |
| --gap | 카드 사이 간격 | 12px | (동일) |
| --pad | 카드 안쪽 여백 | 14px | (동일) |
| --fs-base / --fs-big / --fs-small | 글자 크기 3단 | 14/28/12px | (동일) |

- 차트 색은 위 변수를 재사용 중: 양봉=--buy, 음봉=--sell, MA5선=--accent, MA20선=--muted.
  차트 전용 색을 따로 쓰고 싶으시면 "차트 색 4종"으로 별도 지정해 주셔도 됩니다(변수 추가는 개발이 함).
- 웹폰트를 쓰고 싶으시면 상업용 무료(예: Pretendard)로 지정해 주세요. 파일은 개발이 심습니다.
