## 파트 A — 디자이너에게 보낼 메시지 (이것만 복붙)

```
안녕하세요! 저희 해커톤 프로젝트 웹 화면 디자인을 부탁드리고 싶어요 🙏

[어떤 서비스냐면]
AI가 사용자가 정한 예산 안에서 알아서 주식을 사고파는 서비스예요.
"예산 100달러, 한 번에 최대 50달러까지" 이렇게 한도만 정해두면
AI가 시세를 보고 스스로 판단해서 사고팔고 결제까지 합니다.

기능은 다 돌아가는데 디자인이 하나도 없는 상태예요 (스크린샷 첨부드려요).
여기에 색이랑 글꼴, 여백만 입혀주시면 저희가 코드로 옮길게요.

[부탁드리는 것]
첨부한 대시보드 화면 하나요. 요소 위치나 구성은 자유롭게 바꾸셔도 됩니다.
(여유 되시면 로그인 화면이랑 서비스 소개 페이지도 좋지만, 없어도 괜찮아요)

[원하는 느낌]
"내 돈을 맡겨도 되겠다" 싶은 신뢰감 + AI가 지금 일하고 있는 느낌.
토스증권처럼 깔끔한 금융 앱 톤을 생각하고 있는데,
더 좋은 방향이 보이시면 그쪽으로 가주세요. 믿고 맡길게요!

[형식]
Figma, PNG, PPT 뭐든 편한 걸로요. 색을 알아볼 수만 있으면 됩니다.
다크 모드도 있으면 좋은데, 번거로우면 밝은 화면만 주셔도 돼요.

[일정]
8/3(월) 대회 제출이라 7/29(수)쯤 받으면 여유로워요.
빠듯하시면 편하게 말씀해주세요, 맞출 수 있어요!

궁금한 거 있으면 아무거나 물어봐주세요 🙇
```

**첨부**: 현재 화면 스크린샷 2장(빈 화면 + 실행 중). 끝. 다른 문서 안 보냄.

## 파트 B — 디자이너가 "더 자세히 알려달라"고 할 때만 보낼 것

먼저 보내지 않는다. 요청이 오면 필요한 부분만 골라서 답한다.

**화면 구성 (스크린샷 위에서부터)**
상단 바(서비스명·상태 배지·시작/정지 버튼) → 시세 카드(현재가+캔들차트) →
작은 카드 5개(포지션 / 예산 게이지 / 한도 설정 / 실현손익 / 평가손익) →
AI 판단 타임라인(내부 스크롤) → 이벤트 로그(내부 스크롤) → 거래 내역 표 → 우하단 토스트 알림

**색이 의미를 갖는 곳** — 여기만 구분되면 나머지는 자유
- 오름/매수 vs 내림/매도 (초록 vs 빨강 계열이면 무난)
- AI가 판단한 건지 규칙이 판단한 건지 (배지 2색)
- 정상 / 주의(거부됨) / 위험(긴급정지)

**개발이 알아서 하는 것**: 반응형, hover 효과, 차트 그리기, 다크 모드 전환.
아이콘은 지금 이모지(▶ ■ 🛑 🔔)이고, 아이콘을 주시면 교체하고 없으면 그대로 둔다.

## 파트 C — 우리 내부용: 시안 받은 뒤 할 일

시안이 오면 이 표의 값을 채워 `web/static/css/theme.css`를 교체한다(작업 반나절).
**디자이너에게 이 표를 채워달라고 하지 않는다** — 시안에서 우리가 스포이드로 뽑는다.

| 변수 | 용도 | 현재 라이트 | 현재 다크 |
|---|---|---|---|
| --bg | 페이지 바탕 | #f4f5f7 | #14161a |
| --card-bg | 카드 바탕 | #ffffff | #1e2126 |
| --text | 본문 글자 | #1c2330 | #e6e9ee |
| --muted | 보조 글자 | #6b7480 | #9aa3ad |
| --border | 테두리 | #dfe3e8 | #343a42 |
| --accent | 강조(버튼·링크·MA5선) | #4f6ef7 | #7c93ff |
| --danger | 위험(정지·오류) | #e5484d | #ff6b6e |
| --ok | 성공(체결·연결됨) | #2f9e68 | #3ecf8e |
| --warn | 주의(거부·폴백) | #c97e0a | #f0b429 |
| --buy | 매수·양봉(상승) | #2f9e68 | #3ecf8e |
| --sell | 매도·음봉(하락) | #e5484d | #ff6b6e |
| --badge-gemini | AI 판단 배지 | #7c5cff | #9d86ff |
| --badge-rule | 규칙 판단 배지 | #6b7480 | #7d8590 |
| --badge-fallback | 폴백 판단 배지 | #c97e0a | #f0b429 |
| --badge-dca | 적립식 배지 | #0f7ea8 | #2fa8d5 |
| --font / --mono | 본문·숫자 글꼴 | system-ui / Consolas | (동일) |
| --radius / --gap / --pad | 모서리·간격·여백 | 10 / 12 / 14px | (동일) |
| --fs-base / --fs-big / --fs-small | 글자 크기 3단 | 14 / 28 / 12px | (동일) |

**다크 시안을 안 주시면**: 라이트 값에서 명도만 뒤집어 우리가 만든다(지금 다크 팔레트가 이미 동작하므로 최악의 경우 현행 유지도 가능).

- [ ] 일정 날짜(7/29)가 발송일 기준으로 맞는지
- [ ] 보수·사례는 메시지에 없음 — 관계에 맞게 직접 이야기
