# 인트라바 합성 재생 (Intraday Synthesis) — 상세 기록

> 작성 2026-07-25. 사용자 요청 #2("실제 시세는 더 짧은 간격으로 변동하니 이를 고려")에 대한 구현.
> **핵심 상태: 기능은 정확히 동작하나 "특정 조건에서만" 수익에 유리 → 사용자 결정으로 수정 보류(옵션 유지).**

---

## 1. 무엇인가 — 한 줄

**하루치 실제 일봉(OHLC) 하나를, 하루당 N개의 "합성 인트라바"로 쪼개어 재생**해서, 더 짧은
시간 간격의 시세 변동을 재현하는 재생 모드다. 실제 분/시간봉이 아니라 **합성(가상)**이며 데모용이다.

## 2. 왜 실 인트라데이가 아니라 합성인가 (사용자와 확정)

- 무료로 받을 수 있는 실제 분/시간봉은 **이력이 짧아 2022 하락장(추세추종 실증 무대)을 못 덮는다.**
- 데모의 대표 시나리오(`_bear.csv` = 2022 폭락→2023 회복)를 인트라바로도 보여주려면, 실 일봉을
  기반으로 하위 경로를 **합성**하는 방식이 유일하게 성립한다. → 사용자가 "합성" 방식을 선택.

## 3. 합성 메커니즘 (결정론적 — 재현 가능)

각 실제 일봉 `(시가 O, 고가 H, 저가 L, 종가 C)`를 지나는 **조각선형 경로**로 N개 인트라바를 만든다:

- **상승일(종가 ≥ 시가)**: `O → L → H → C` (눌림목 먼저 찍고 반등해 마감)
- **하락일(종가 < 시가)**: `O → H → L → C` (고점 먼저 찍고 하락해 마감)

경로를 3구간(각 1/3)으로 균등 분할하고, `t=(k+1)/N (k=0..N-1)`에서 선형 보간해 각 인트라바의 종가를 뽑는다.

**보존되는 성질(중요)**:
- **하루의 마지막 인트라바 종가 == 실제 일봉 종가** (오차 0). → **일 단위 궤적은 실데이터 그대로**,
  하위 경로만 합성이다. (검증: AAPL_bear 481일에서 마지막 인트라바 종가가 실 일봉 종가와 0 불일치.)
- 모든 인트라바 종가는 그날 `[저가, 고가]` 범위 안.
- 봉 수 = N × 일봉 수 (예: AAPL_bear 481일 × 4 = 1924봉).

구현: `market/price_feed.py`
- `IntradayReplayFeed(ReplayPriceFeed)` — start/end/warmup 슬라이싱을 **일 단위로 먼저** 한 뒤 확장.
- `_seg_interp(waypoints, t)` — 4웨이포인트(3구간) 조각선형 보간.
- `_explode(bars, sub)` — 일봉 리스트를 인트라바 리스트로 확장(정적 메서드, 순수 함수).

## 4. 사용법

- **웹 대시보드**: "봉 간격" 드롭다운 — 일봉(1) / 인트라바 2·4·8봉/일. (실데이터 재생일 때만 표시)
- **엔진**: `feed.sub_bars` (1~12로 클램프). `web/engine.py._replay_feed()` 가 sub>1 이면 인트라바 피드 생성.
- **백테스트**: `python scripts/backtest.py ... --sub-bars 4` (단일 종목 경로).
- **서버 API**: `FeedBody.sub_bars` (기본 1).

## 5. ⚠ 성능 실측 — "특정 조건에서만" 유리하다

인트라바로 쪼개면 이동평균(MA5/MA20)이 **인트라바 단위**로 계산되어 아주 짧은 변동에도 신호가 반응한다.
이것이 취지("짧은 간격 반영")지만, **대가로 잦은 매매(휩쏘 = 속임수 신호에 낚인 매매)가 폭증**한다.

| 종목/전략 (하락장 5/20 골든크로스) | 일봉 | 인트라바 4봉/일 |
|---|---:|---:|
| TSLA 예산 수익률 | **+81.29%** | **−35.49%** |
| 매매 횟수 | 21회 | 108회 (5배) |
| 수수료 | 7.17 USDC | 22.71 USDC (3배) |
| 최대낙폭(MDD) | 35% | 59% |

- **원인**: 인트라바가 하루 안에서 `저가↔고가`를 오가므로 MA가 자주 교차 → "고가 부근 매수 → 저가
  부근 매도"가 반복되며 큰 승리를 잘게 잘라먹는다. (같은 성질을 1/5 신호도 공유 — 둘 다 "더 자주 반응".)
- **잘 되는 조건**: 추세가 오래 한 방향으로 지속되고 되돌림(휩쏘)이 적은 구간에서만 인트라바/1-5가
  일봉과 비슷하거나 근소 우위. 그 외 대부분 구간에서는 수익을 깎는다.
- **결론**: **30% 목표에는 "일봉 + 추세추종(가격>MA20 또는 5/20) + 멀티 종목"이 최적**
  (3종목 하락장 pxma20 = +77.55%, 가드 유출 0). 인트라바·1/5는 "현실감/옵션"으로 제공.

## 6. ⚑ 결정 — 수정 보류 (2026-07-25, 사용자)

**"특정 조건에서만 잘 작동한다"는 이 성질을 지금은 고치지 않고 보류한다.**
- 인트라바·1/5 신호를 **제거하지 않고, 튜닝(휩쏘 억제 필터 등)도 하지 않고**, 지금 상태 그대로 옵션으로 둔다.
- 수익 시연·30% 확인은 **일봉 + 추세추종 + 멀티**로 한다(위 §5 결론).
- 후속(필요 시): 인트라바에 휩쏘 억제(예: 확인봉·히스테리시스·최소 보유틱)를 얹으면 조건 의존을 줄일 여지가
  있으나, 마감·402 Guard 초점을 고려해 **지금은 착수하지 않는다.**
